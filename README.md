- Track daily progress transparently

## 📌 About This Journey

I am starting this journey with a **strong focus on fundamentals**, real-world tooling, and disciplined documentation.

Instead of rushing into tools, this repository emphasizes:
- Clean environment setup

- Daily technical logs

- I can reflect on growth over time
- Recruiters or collaborators can understand my learning path
